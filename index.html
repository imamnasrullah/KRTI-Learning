Peta Pembelajaran

Materi Pembelajaran

Dua materi mengikuti alur pengembangan simulasi drone KRTI.

MATERI 01 · GATE 1–2

Dasar Pengendalian Manual Drone

Memahami kendali dasar drone dan latihan melewati Gate 1 dan Gate 2 secara manual.

  • Komponen dan prinsip kerja quadcopter.
  • Mode penerbangan dan kendali dasar.
  • ARM, takeoff, hover, arah, dan pendaratan.
  • Latihan lintasan manual di Gazebo.
MATERI 02 · GATE 3–5

Navigasi Otomatis Berbasis ArUco

Mengenal marker ArUco sebagai referensi visual untuk membantu drone mengenali gate.

  • Pengertian dan fungsi marker ArUco.
  • Deteksi marker melalui kamera.
  • Alur navigasi otomatis Gate 3–5.
  • Validasi deteksi dan penanganan kegagalan.
Materi 01

Pengendalian Manual · Gate 1–2

Fokus pembelajaran adalah memahami kendali dasar dan menjaga kestabilan drone sebelum melewati gate.

01

Persiapan

Periksa model drone, koneksi SITL–Gazebo, sensor simulasi, mode penerbangan, dan area lintasan.

02

Kendali dasar

Pelajari ARM, takeoff, hover, gerak maju/mundur, kiri/kanan, yaw, serta perubahan ketinggian secara bertahap.

03

Lintasan gate

Latih pendekatan dan lintasan melewati Gate 1–2. Amati posisi, ketinggian, heading, dan kestabilan.

Catatan keselamatan simulasi: verifikasi posisi, arah gate, dan koordinat sebelum menjalankan perintah gerak otomatis.
Materi 02

Navigasi Otomatis ArUco · Gate 3–5

Marker visual menjadi referensi bagi sistem untuk mengenali target dan membantu proses navigasi.

1. Pengenalan marker

ArUco merupakan pola visual terkode yang dapat dideteksi kamera dan memiliki identitas marker.

2. Deteksi dan estimasi

Sistem memproses citra untuk menemukan marker dan, sesuai konfigurasi kamera, memperkirakan posisi relatifnya.

3. Logika navigasi

Program menentukan tindakan berdasarkan marker yang terdeteksi, posisi relatif, dan tahapan Gate 3–5.

4. Validasi

Uji beberapa jarak dan sudut. Periksa marker hilang, deteksi keliru, respons kendali, dan prosedur abort.

Catatan: ID marker, parameter kamera, algoritma, dan urutan gerak harus disesuaikan dengan implementasi aktual proyek KRTI.
Lingkungan Praktik

Simulasi dengan Gazebo

Gazebo dijalankan pada komputer yang memiliki lingkungan ArduPilot SITL dan model dunia KRTI. Website ini menjadi panduan belajar, bukan pengganti aplikasi Gazebo.

Perangkat simulasi

  • Ubuntu dan Gazebo Harmonic.
  • ArduPilot SITL / ArduCopter.
  • Model drone dan world KRTI 2026.
  • Program Python untuk navigasi.

Alur pengujian

  1. Jalankan world KRTI di Gazebo.
  2. Jalankan ArduPilot SITL.
  3. Pastikan koneksi MAVLink normal.
  4. Uji pengendalian manual terlebih dahulu.
  5. Uji ArUco setelah deteksi dan koordinat tervalidasi.

Aktivitas Siswa

Panduan Praktikum

01

Observasi

Amati model drone, gate, arah lintasan, dan perangkat simulasi. Catat fungsi komponen utama.

02

Eksperimen

Latihan kendali manual Gate 1–2, kemudian amati proses deteksi marker untuk Gate 3–5.

03

Analisis

Catat kesalahan lintasan, kestabilan, keberhasilan deteksi, dan hasil pengujian.

Cek Pemahaman

Evaluasi Singkat

1. Apa tujuan latihan manual pada Gate 1–2?

Melatih kendali dasar, kestabilan, arah, ketinggian, dan kemampuan mengarahkan drone melewati gate.

2. Apa fungsi marker ArUco pada Gate 3–5?

Marker menjadi referensi visual yang dapat dideteksi kamera untuk membantu sistem mengenali target.

3. Mengapa koordinat dan arah gate harus diverifikasi?

Kesalahan koordinat atau orientasi dapat membuat drone bergerak ke arah yang tidak sesuai.

4. Mengapa pengujian perlu dilakukan bertahap?

Agar respons sistem dapat diamati dan masalah ditemukan lebih awal.
